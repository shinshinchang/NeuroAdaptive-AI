# 線上示範頁（不需安裝擴充功能）

公開網址：https://wenzhotw.github.io/NeuroAdaptive-AI/

這個資料夾是給老師或評審直接在瀏覽器裡試用的獨立示範頁。擴充功能的滑鼠／捲動負荷計算與專注模式（四步轉換、閱讀尺、段落模式、一鍵復原）已寫進 `index.html`，不需要安裝 Chrome 擴充功能。

- 介面以繁體中文為主，並附簡短英文說明。
- 預設開啟 Demo 模式（門檻 50、持續 1.5 秒），也可按「直接開啟專注模式」。
- 所有滑鼠與捲動資料只在這個分頁的記憶體裡計算，不會上傳。
- 本工具是自我覺察的輔助，**不是醫療診斷**。

本頁也會一併提交到 `chrome-extension-demo` 分支，並用 GitHub Pages（`gh-pages` 分支根目錄）發布。
