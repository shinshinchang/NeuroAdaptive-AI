# NeuroAdaptive AI – Chrome 擴充功能 Demo（專注模式）

> 不需要額外硬體，只用瀏覽器裡的滑鼠微行為，即時估算「注意力負荷」，偏高時溫和提醒，並一鍵把網頁變成專注模式。
> **定位：自我覺察的輔助工具，不做醫療診斷。** 所有資料只在本機分頁記憶體內計算，不上傳、不儲存原始軌跡。

展示影片：[`NeuroAdaptive_demo.mp4`](NeuroAdaptive_demo.mp4)（約 87 秒，1280×720，剪紙動畫＋實機錄影）

## 安裝（1 分鐘）
1. Chrome 打開 `chrome://extensions`，右上角開啟「開發人員模式」。
2. 按「載入未封裝項目」，選 `chrome-extension-demo/extension` 資料夾。
3. 打開示範頁：在 `chrome-extension-demo/` 資料夾執行 `python3 -m http.server 8765`，瀏覽 `http://localhost:8765/demo-site/index.html`。
   （或直接雙擊 `demo-site/index.html`，但要在擴充功能「詳細資料」裡開啟「允許存取檔案網址」。）
4. 右上角會出現「注意力負荷（即時）」圓形儀表；點儀表可展開 5 個分項。

## 功能
- **即時偵測**：每 0.4 秒用最近 12 秒的滑鼠移動與捲動計算 0–100 分（平滑處理），低／中等／偏高三色。
- **溫和提醒**：分數「偏高」持續 3 秒（Demo 模式 1.5 秒）才跳出「偵測到注意力負荷偏高，要開啟專注模式嗎？」，可選「開啟／稍後」，按稍後 60 秒內不再打擾。
- **專注模式（分層轉換，每層約 1 秒）**：① 廣告淡出 → ② 側欄、推薦、留言、浮動視窗滑走 → ③ 降低彩度、停止動畫／GIF／自動播放 → ④ 放大字級、行距、單欄閱讀。左下角有「↩ 一鍵復原」。
- **閱讀尺**：只亮目前這一行，其他變暗。**分段呈現**：一次只亮一段（其他段落變淡），上方進度條、←→ 鍵或按鈕切換。
- **休息提醒**：專注模式中負荷仍持續偏高 60 秒，顯示 1 分鐘呼吸動畫（popup 也可手動叫出）。
- **Popup**：開關偵測、靈敏度 ×0.6–1.6、Demo 模式（門檻降低，攤位用）、顯示滑鼠軌跡、自動提示開關、手動專注模式／閱讀尺／分段／休息、**重置（換下一位體驗者）**、隱私說明。

## 指標怎麼對應原本的專案（NeuroAdaptive-AI-v0.1/js/analyzer.js）
原型的權重與門檻沿用 v0.1，只把 Go/No-Go 專用特徵換成「自由瀏覽」量得到的對應特徵：

| v0.1（Go/No-Go） | 權重 | 擴充功能（自由瀏覽） | 正規化 |
|---|---|---|---|
| RT CV 反應時間變異 | 0.30 | 移動節奏不穩：滑鼠速度變異係數 CV | (CV−0.55)/0.9 |
| Commission 誤按 | 0.28 | 突發甩動：速度 >2200 px/s 的片段比例 | ratio/0.22 |
| Omission 漏按 | 0.20 | 來回捲動：12 秒內方向反轉且該段 ≥120px 的次數 | 次數/6 |
| Direction changes | 0.12 | 每秒方向急轉（>90°）次數 | (n−0.6)/4 |
| Speed SD | 0.10 | 速度標準差 | SD/900 |

門檻同 v0.1：≥65 偏高、≥35 中等（Demo 模式 50／28）。幾乎沒動時（<1 秒有效移動）不判斷。
**注意：這些是透明的原型規則，尚未經資料驗證，不能當作臨床切點。**

## 攤位 3 分鐘 Demo 腳本
1. **(0:00–0:30) 開場**：「你沒有不專心，是網頁太吵了。」打開示範新聞頁，讓來賓正常讀第一段，儀表維持綠色低分。
2. **(0:30–1:10) 偵測**：請來賓快速亂晃滑鼠、上下來回捲動（模擬分心找東西）。在 popup 開「顯示滑鼠軌跡」，點儀表展開 5 個分項，說明哪些行為讓分數上升。
3. **(1:10–1:30) 提醒**：分數轉紅、持續幾秒後跳出提示卡 → 讓來賓自己按「開啟」（強調：由使用者決定，不替人貼標籤）。
4. **(1:30–2:20) 轉換**：看網頁一層層變乾淨；示範閱讀尺、分段呈現；來賓平穩閱讀，分數降回綠色。按「↩ 一鍵復原」對比前後。
5. **(2:20–3:00) 收尾**：打開 popup 講隱私（只在本機計算）與定位（自我覺察工具、非診斷）；按「重置」換下一位。
- 建議開「Demo 模式」+ 靈敏度 ×1.3–1.5，讓現場比較容易觸發。現場網路不穩時直接播影片。

## 已知限制
- 權重與門檻是人工設定，尚未用受試者資料校正；下一步：個人基準線校準（前 20–30 秒）、用試用資料比較人工權重 vs 邏輯迴歸。
- 「找正文」是啟發式（找直屬 `<p>` 字數最多的容器），在複雜網站（SPA、無限捲動）可能不完美。
- 只用滑鼠與捲動，觸控板／觸控螢幕的行為分布不同，需另外調整。
- Playwright 錄影裡的滑鼠移動是腳本模擬的（影片中分數為擴充功能即時計算的真實數字）。
